# TradingAgents

А этот репозиторий теперь содержит **две платформы**:

1. **TradingAgents** (эта, порт **3003**) — автоторговля, бэктесты, оптимизатор стратегий.
   Запуск — `start.bat` / `start.sh` в корне.
2. **TradeVision Portal** (папка `portal/`, порт **3005**) — отдельный
   ультра-современный портал: неон-терминал на графиках Lightweight Charts
   (TradingView) с данными Bybit, совет AI-агентов с выбором любых моделей
   justcode.lol, live-сигналы по watchlist'у и полный AI-разбор ваших реальных
   сделок (read-only ключи Bybit или CSV-экспорт).
   Запуск — `portal\start.bat` / `./portal/start.sh`, подробности — `portal/README.md`.
   Тесты и CI: `./portal/run_tests.sh` (pytest, сеть не нужна) +
   `.github/workflows/portal-ci.yml` (тесты, bandit, pip-audit, проверка секретов).
   Боевой деплой: `DOMAIN=ваш_домен bash portal/deploy/deploy.sh`.
   Платформа никогда не тратит AI-токены без вашей команды.

---

## TradingAgents — платформа для дэйтрейдинга

Профессиональная платформа, которая **сама** ищет сделки (лонг и шорт), прогоняет
стратегии на истории (бэктест) и выдаёт сигналы в реальном времени. Внутри —
**5 AI-моделей**, которые советуются между собой и приходят к общему решению.

## 🚀 Как запустить (самая простая инструкция)

Вам **не нужно** знать программирование и **не нужен** Docker / Codespace.
Нужен только Python, установленный на компьютере.

### Шаг 1. Скачайте проект

Скачайте репозиторий к себе на компьютер (кнопка **Code → Download ZIP** на
GitHub и распакуйте), либо:

```
git clone https://github.com/cotpowet61-sys/TradingAgents.git
```

`README.md` — это просто **инструкция**, которую вы сейчас читаете. Её можно
открыть в любом текстовом редакторе, но делать это не обязательно.

### Шаг 2. Установите Python (один раз)

1. Откройте сайт **https://www.python.org/downloads/**
2. Нажмите большую жёлтую кнопку **Download Python**.
3. Запустите скачанный файл.
4. **ВАЖНО:** поставьте галочку ✅ **«Add Python to PATH»** в самом низу окна.
5. Нажмите **Install Now**.

### Шаг 3. Запустите платформу (двойной клик)

* **Windows:** дважды кликните по файлу **`start.bat`**
* **Mac / Linux:** дважды кликните по файлу **`start.sh`**

Всё остальное (установка библиотек, настройка) произойдёт **автоматически**.
Через несколько секунд в браузере откроется сайт: **http://localhost:3003**

> Терминал/командная строка **не нужны** — просто двойной клик по `start.bat`.
> Закрыли окно с сервером — сайт выключился. Запустите тем же файлом — включится.

## 🔑 Куда вводить ключи (только 1 раз)

Ключи вводятся **прямо на сайте**, без правки файлов:

1. Откройте вкладку **«Настройки»** вверху.
2. В поле **«Глобальный API-ключ»** вставьте ваш ключ от
   `https://api.justcode.lol/v1` — он автоматически подойдёт для всех 5 моделей.
3. **Base URL** уже заполнен: `https://api.justcode.lol/v1` (менять не нужно).
4. Ниже, если хотите, можно поменять имя каждой модели или дать ей отдельный ключ.
5. Нажмите **«💾 Сохранить»**, затем **«🔌 Проверить все модели»**.

Зелёная галочка ✓ напротив модели = модель отвечает. После этого бейдж в шапке
сменится с **DEMO** на **LIVE · AI**.

> **Рыночные данные — с бессрочных USDT-фьючерсов Bybit (`linear`).** Графики,
> тикеры и сигналы берутся из публичного API **без ключей**. Если у монеты нет
> фьючерса, платформа автоматически пробует спот и обратно (например, **LSKUSDT**
> торгуется на Bybit только в фьючерсах — он будет корректно показан как PERP).
> Монеты, которых нет ни там, ни там, помечаются «нет на Bybit» — платформа
> не подставляет выдуманные цены. Источник цены всегда виден: бейдж в шапке
> **«📡 Bybit Live»** (реальные данные) или **«⚠️ Учебные данные»** (API
> недоступен — кнопка «Проверить Bybit» в Настройках).

> Ключи сохраняются в файл `.env` в папке проекта и никуда не отправляются.
> Файла `.env` нет в архиве/репозитории специально (чтобы ключи не утекли) —
> он **создаётся автоматически** при первом запуске из шаблона `.env.example`.
> Если `.env` удалили — просто запустите платформу: файл появится пустым,
> введите ключи в «Настройках» ещё раз и нажмите «Сохранить».

> **Экономия токенов AI.** Агенты можно выключать — по одному или все сразу:
> - **Тумблер каждого агента** — на вкладке «Монета» (блок «🧠 Агенты анализа»)
>   и в «Настройках» (галочка «вкл» у каждой модели). Выключенный агент не
>   вызывает AI и **не тратит токены вообще** — ни в фоне, ни в ручном анализе.
> - **«Фоновый сканер с AI»** — выключен по умолчанию (`AGENTS_AUTO_ANALYSIS=false`):
>   фоновый мониторинг всех монет работает на чистых индикаторах (0 токенов),
>   а агенты вызываются только когда вы сами жмёте «🤖 Анализ агентов».
>   Включайте его, только если готовы к большому расходу токенов.

> **Анализ агентов без привязки к стратегии.** Кнопка «🤖 Анализ агентов» не
> навязывает моделям конкретную стратегию: платформа сама подбирает её по тому
> графику, что на экране — прогоняет быстрый бэктест **всех 23 стратегий** по
> свежим свечам и берёт лучшую (результат кэшируется 15 минут). В дереве анализа
> видно пометку «⚡ авто-подбор», топ-5 стратегий с их winrate/PnL, а агенты
> получают это сравнение в контексте и опираются прежде всего на собственный
> анализ индикаторов и свечей — могут предложить и другой тип стратегии.

**Про Bybit (важно):** ❌ Ключи Bybit **НЕ нужны** для графиков, бэктестов и
сигналов. Котировки (свечи) загружаются через **публичный** API без ключей, а
график TradingView работает сам по себе. Ключи Bybit понадобятся **только** в
будущем, если захотите торговать реальными деньгами. Сейчас достаточно ввести
только **AI-ключ** от `api.justcode.lol/v1`.

> **Сигналы работают БЕЗ AI-ключа.** Сигналы считаются индикаторами
> математически — они появляются и без ключа. Ключ нужен только для разделов
> «Анализ агентов» (рассуждения моделей) и «Ассистент». Поэтому не удивляйтесь,
> что сигналы есть уже сейчас — это нормально.

**Важно про модели:** по умолчанию всё идёт через ваш endpoint
`https://api.justcode.lol/v1` (OpenAI-совместимый протокол). Имена моделей уже
подставлены:

| Роль | Модель |
|---|---|
| 🧠 Ведущий стратег | `gpt-6-astra` |
| ⚡ Аналитик моментума | `gpt-5.6-sol` |
| 🦅 Контрариан | `grok-4.5` |
| 💎 Макро | `gemini-2.5-pro` |
| 🛡️ Риск-менеджер | `claude-fable-5` |

Если у вашего провайдера модели называются иначе — просто поменяйте имя в
интерфейсе (например `claude-fable-5` → нужное вам имя).

## 🖥 Что есть на сайте (7 вкладок)

**Каждая вкладка:**

1. **Дашборд** — график цены Bybit-стиля (OHLC-легенда, бейдж последней цены,
   сетка, кроссхейр; TradingView — опционально по кнопке), список **всех монет
   с суточным объёмом больше $1 млн**, журнал агентов и **дерево размышлений**.
   В шапке бейдж **«📡 Bybit Live»** (реальные данные) или **«⚠️ Учебные
   данные»** (Bybit недоступен — проверьте интернет; кнопка «Проверить Bybit»
   в Настройках).

2. **🎯 Монета** — работа с одной монетой:
   - слева **все монеты Bybit по алфавиту** (объём ≥ $1M/сутки) с поиском,
     обновляются с биржи каждую минуту;
   - по центру **график выбранной монеты** с переключателем таймфреймов;
   - кнопка **«🤖 Анализ агентов»** — 5 моделей разбирают именно этот график;
   - справа **«🟢 Live 1-на-1»**: запуск сигналов **только по этой монете**
     (параллельно общему лайву). Все настройки — стратегия (или «Авто»),
     параметры, TP, SL, удержание, лимит сделок/день, размер позиции — меняются
     **онлайн кнопкой «✔ Применить»** без остановки.

3. **Стратегии** — **23 готовые стратегии** (пробой, RSI, MACD, стохастик, ADX,
   Supertrend, Parabolic SAR, Ишимоку, Боллинджер, VWAP и др.), можно менять
   параметры и добавлять свои.

4. **Бэктест** — проверка стратегии на истории. **Количество данных считается
   автоматически из выбранных дат и таймфрейма** (поля «Период с / по»); без дат
   — последние 24 часа. Кнопка **«⚡ Все 23 стратегии»** — сравнительная
   таблица с лучшей стратегией монеты в один клик. Сверху — **«Подобрать»**:
   те же прогоны + сохранение топ-стратегий для live-режима.

5. **Live-сигналы** — общий лайв по всем монетам: активные сигналы (BUY/SELL
   с уровнями входа/TP/SL) и история. Для каждой монеты автоматически берётся
   **её лучшая стратегия** (из оптимизации).

6. **🧑‍💻 Ассистент** — выбранная модель пишет код по вашему запросу (новая
   стратегия, правка интерфейса) и сохраняет в файл проекта.

7. **Настройки** — AI-ключи, модели, правила торговли, **проверка соединения
   с Bybit**. Сохранение работает без перезапуска платформы.

## 📏 Правила торговли (уже встроены)

| Правило | Значение |
|---|---|
| Сделок в день, максимум | **30** |
| Take-Profit, минимум | **2%** движения цены |
| Удержание сделки, максимум | **4 часа** |
| Stop-Loss | 1% (соотношение риск/прибыль ≈ 1:2) |
| Направление | и лонг, и шорт |

Все правила можно поменять в разделе «Настройки» → «Правила торговли».

## 🎯 Как добиться лучших результатов (оптимизация)

На вкладке **Бэктест** сверху есть кнопка **«⚡ Подобрать лучшие стратегии»**:

1. Выберите монету и таймфрейм.
2. Нажмите — система прогонит **все 23 стратегии** на истории и покажет топ по
   win rate / PnL / числу сделок.
3. Отобранные стратегии (галочка ✅) **сохраняются в профиль монеты** и
   автоматически используются в live-режиме — для каждой монеты своя лучшая
   стратегия, в разный момент времени.

Это и есть та самая «гибкость»: вместо одной стратегии на всех — **адаптивный
подбор** лучшей стратегии под каждую монету.

> **Честно про win rate 70%+:** на синтетических (демо) данных результат будет
> высоким почти всегда. На реальном рынке при цели TP=2% / SL=1% win rate выше
> ~60–65% достигается редко — это нормально для торговли с соотношением 2:1
> (прибыль даёт не только % побед, но и размер выигрыша). Оптимизатор помогает
> выбрать лучшие из имеющихся стратегий, но **не гарантирует** 70%+ на живом
> рынке. Подключите реальные котировки Bybit — и вы увидите честную картину.

## ⚠️ Честное предупреждение

* В демо-режиме (без ключей) данные — **синтетические** (реалистичные, но
  ненастоящие). С AI-ключом подключаются реальные модели; котировки Bybit —
  публичные, работают без ключей (это реальный рынок).
* Платформа выдаёт **сигналы**, а не торгует сама. Реальное исполнение ордеров —
  следующий шаг (можно добавить).
* Никакая стратегия не гарантирует прибыль. Всегда проверяйте на бэктесте и
  торгуйте осторожно.

## 🧰 Для тех, кто в коде разбирается

* Backend: `backend/` (FastAPI). Запуск вручную: `cd backend && python main.py`
* API-документация: `http://localhost:3003/docs`
* Docker: `docker compose up --build` (фронт на `:8080`, API на `:3003`)
* Структура и архитектура описаны в комментариях к каждому модулю.

Добавить свою стратегию: создайте класс в `backend/strategies/builtin.py`
(метод `generate`) и добавьте его в словарь `BUILTIN_STRATEGIES` — он сразу
появится в интерфейсе.
