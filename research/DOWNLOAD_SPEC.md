# Что скачать (контракт данных)

Исследовательский контур не ходит на биржу сам по вашим деньгам и не требует ключей:
нужны только **публичные свечи**. Скачать можно двумя способами — выберите любой.

## Вариант A. Встроенный загрузчик (проще всего)

```bash
cd /path/to/TradingAgents
python research/run.py download \
  --symbols BTCUSDT,ETHUSDT,SOLUSDT,BNBUSDT,XRPUSDT,DOGEUSDT,ADAUSDT,AVAXUSDT,LINKUSDT,TONUSDT,SUIUSDT,APTUSDT,ARBUSDT,OPUSDT,NEARUSDT,ATOMUSDT,LTCUSDT,DOTUSDT,FILUSDT,INJUSDT,TIAUSDT,SEIUSDT,STXUSDT,RUNEUSDT,AAVEUSDT,UNIUSDT,ETCUSDT,FETUSDT,PEPEUSDT,WIFUSDT \
  --timeframes 15m,1h \
  --days 180
```

Скрипт сам:
- бьёт запросы по 1000 свечей (Bybit V5 `/v5/market/kline`), проходит всю историю за 180 дней;
- перебирает резервные хосты `api.bybit.com → api2 → bytick → bybit.eu` (первый доступный);
- сохраняет в `research/data/<СИМВОЛ>_<ТФ>.csv`, пишет `research/artifacts/data_manifest.json`;
- проверяет качество (дырки, дубли, битые OHLC) и предупредит, если данных мало.

Ключи API не нужны: это публичный эндпоинт. Загрузчик работает и на сервере, и дома.

## Вариант B. Свои выгрузки

Если удобнее выгрузить из веб-интерфейса Bybit/TradingView/биржи — положите файлы
в `research/data/` со строгим контрактом:

```
research/data/BTCUSDT_15m.csv
research/data/BTCUSDT_1h.csv
research/data/ETHUSDT_15m.csv
...
```

Формат — CSV с заголовком, ровно такие колонки (порядок не важен, лишние можно):

| колонка | смысл |
|---|---|
| `ts` | время **открытия** бара, миллисекунды UTC (Bybit отдаёт именно так) |
| `open` | цена открытия |
| `high` | максимум бара |
| `low` | минимум бара |
| `close` | цена закрытия |
| `volume` | объём в базовой монете |

Пример строки:

```csv
ts,open,high,low,close,volume
1735689600000,93450.1,93620.5,93210.0,93555.7,412.33
```

## Сколько и что качать (рекомендация)

| параметр | значение | почему |
|---|---|---|
| монет | **30–40** | нужна перекрёстная проверка: правило, работающее на 3 монетах, — это случайность |
| период | **последние 6 месяцев (180 дней)** | на 15m это ≈17 280 бар, на 1h ≈4 320 — хватает и на обучение, и на вневыборочную проверку |
| таймфреймы | **15m и 1h** | 15m — то, на чём портал сканирует по умолчанию; 1h — как второй, более спокойный контур |
| монеты | топ по ликвидности + пара «своих» | ликвидность важна: спред и проскальзывание на тонких монетах съедают всю статистику |

Готовый список (30 монет, все торгуются на Bybit линейно):

```
BTCUSDT,ETHUSDT,SOLUSDT,BNBUSDT,XRPUSDT,DOGEUSDT,ADAUSDT,AVAXUSDT,LINKUSDT,TONUSDT,
SUIUSDT,APTUSDT,ARBUSDT,OPUSDT,NEARUSDT,ATOMUSDT,LTCUSDT,DOTUSDT,FILUSDT,INJUSDT,
TIAUSDT,SEIUSDT,STXUSDT,RUNEUSDT,AAVEUSDT,UNIUSDT,ETCUSDT,FETUSDT,PEPEUSDT,LSKUSDT
```

Если качаете сами — берите **перпетуалы (linear)**: у них объём больше и портал
считает по ним же. Спот тоже подойдёт, но статистика будет чуть отличаться.

## Проверка после выгрузки

```bash
python research/run.py quality
```

Что смотрим:

- `покрытие, %` — сколько бар из ожидаемых реально есть. **Ниже 90% → файл не берём**
  (контур сам откажется: «данные дырявые, анализ не имеет смысла»);
- `дырки` — разрывы больше 1.5 интервала. Несколько на праздники/сбои биржи — норма;
  десятки — признак битой выгрузки;
- `дубли`, `битые OHLC` — должны быть нули.

Объём данных на 30 монет × 2 ТФ × 180 дней — примерно **20–40 МБ CSV**.
Эта папка не попадает в git (см. `.gitignore`): данные — ваши, в репозиторий их не мешаем.
