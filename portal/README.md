# TradeVision Portal

Веб-портал для трейдинга: live-сканер сигналов, AI-совет, партнёрская программа и
SaaS-биллинг. Работает **из коробки без ключей** в демо-режиме и включается в боевой
режим заполнением `portal/.env`.

## Что внутри

| компонент | файл | назначение |
|---|---|---|
| сервер | `server.py` | FastAPI: страницы, API, WebSocket, фоновый сканер |
| настройки | `portal_config.py` | все параметры + валидация запуска + сохранение в `.env` |
| сканер | `live_engine.py` | публичные свечи Bybit → авто-выбор стратегии → фильтры → сигнал |
| стратегии | `../backend/strategies/` | 23 стратегии + индикаторы (без look-ahead) |
| фильтры/цели | `signal_gates.py` | стоп-листы, запретные зоны, плавающие TP/SL, breakeven/трейлинг |
| ИИ-фильтр | `curated.py` | мета-модель из `research/` (включается `USE_CURATED=true`) |
| разбор сделок | `strategy_ranker.py` | анализ сделок с биржи → подбор стратегий и TP/SL |
| обучение на исходах | `signal_learner.py` | авто-стоп-листы по накопленным исходам |
| обучение портфеля | `trades_analytics.py` | анализ CSV-выгрузок пользователя, выводы без AI |
| AI-совет | `council.py`, `llm_client.py` | 6 ролей, вердикт + согласие моделей |
| подключение биржи | `bybit_account.py` | READ-ONLY ключи: баланс, позиции, ордера, история |
| безопасность | `security.py` | заголовки, CSRF/Origin, rate-limit, аудит, шифрование ключей |
| SaaS | `saas_routes.py`, `authn.py`, `billing.py`, `partners.py` | вход, подписка, USDT-оплата, партнёрка |

## Быстрый старт (локально, без ключей)

```bash
cd portal
python -m venv .venv-test && source .venv-test/bin/activate
pip install -r requirements.txt
python server.py                     # http://127.0.0.1:3005
```

Портал запустится в демо-режиме: график синтетический (по нему сигналов не будет —
это сделано намеренно), AI отвечает академически, кошелёк не нужен.

## Тесты

```bash
cd portal && bash ../run_tests.sh           # свои venv + все тесты
# или, если зависимости уже стоят:
cd portal && python -m pytest tests -q
```

## Безопасность (что уже сделано)

- **Пароли**: PBKDF2-HMAC-SHA256, 240k итераций, политика ≥8 символов (блокируем топ-список слабых).
- **Сессии**: HttpOnly + SameSite=Lax cookie, Secure за HTTPS, срок 30 дней, сброс всех сессий при смене пароля.
- **CSRF**: любой POST/PUT/DELETE должен прийти с нашего Origin (проверка по 3 источникам).
- **Rate limit**: в БД (работает и на несколько воркеров): логин 10/5 мин на IP+аккаунт, регистрация 5/час, сброс пароля 3/час, оплата 30/мин.
- **Заголовки**: CSP (без eval), X-Frame-Options SAMEORIGIN, nosniff, Referrer-Policy, HSTS за HTTPS.
- **Тело запроса**: лимит 12 МБ, аккуратный 413.
- **Секреты**: `PORTAL_AUTH_SECRET` и `ADMIN_TOKEN` генерируются при первом запуске и пишутся в `.env` (бэкапить!).
- **Ключи клиентов**: AES-256-GCM (`keyvault.py`), ключ = SHA-256 от `PORTAL_AUTH_SECRET`, в UI только маска.
- **Ключи биржи**: только READ-ONLY. При сохранении портал проверяет ключ на Bybit и отказывается принимать торговые/выводные права.
- **Аудит**: логины, смены пароля, платежи, правки настроек, админ-действия — в таблицу `audit`.
- **Трек-рекорд**: только реальные данные (синтетика не попадает ни в сигналы, ни в исходы, ни в статистику).

## Юридический минимум перед продажей

`static/legal/{imprint,privacy,terms}.html` — готовые шаблоны. Заполните поля `[[...]]`
(оператор, адрес, e-mail, юрисдикция) и попросите юриста проверить, особенно если
продаёте в ЕС: InfoSoc/Impressum, GDPR-информация, потребительское право, налоги.
В шаблонах прямо написано, что это не инвестиционная рекомендация и что результаты
прошлого не гарантируют будущих.

## Разбор сделок и подбор целей (админка)

Откройте `/static/admin.html` (или `/admin.html`), вставьте `ADMIN_TOKEN` и в блоке
«Разбор сделок с биржи» нажмите:

1. **Разобрать сделки** — прогон всех 23 стратегий по реальным свечам;
   результат: разрешённые и запрещённые «стратегия/сторона» по каждой паре,
   предложенный порог уверенности.
2. **Подобрать TP/SL** — перебор целей и стопов на тех же свечах по экономике
   (ожидание на сделку после комиссии и проскальзывания), с полом по TP.
3. **Применить в .env** — запишет `MANUAL_TP_PCT/SL_PCT`, `MIN_CONFIDENCE`,
   `STYPE_BLOCKLIST` и добавит запись в аудит.

То же из консоли: `python strategy_ranker.py --tf 15m --days 30 --optimize [--apply]`.

Дополнительно: исследовательский контур `../research/` прогоняет 30–40 монет за
полгода, перебирает TP/SL/BE/трейлинг с walk-forward и обучает ИИ-фильтр
(`bundle.json` → `USE_CURATED=true`). См. `../research/README.md`.
