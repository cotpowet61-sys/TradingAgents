# TradeVision Portal

Отдельная ультра-современная платформа поверх движка TradingAgents:
AI-совет агентов по графикам Bybit, live-сигналы по вашему watchlist'у
и полный разбор ваших реальных сделок — в неоновом терминальном дизайне.

## Запуск (1 клик)

| Система | Команда |
|---|---|
| Windows | двойной клик по `portal\start.bat` |
| Linux/macOS | `./portal/start.sh` |

Откроется **http://localhost:3005** (основная платформа на 3003 не трогается,
старая на 3001 — тоже). Докер не нужен — поднимается обычное venv-окружение
`.venv-portal` рядом с проектом.

## Что умеет

### 📈 Терминал
- График на официальном **Lightweight Charts от TradingView** (библиотека
  лежит локально в репозитории — никаких CDN), данные — напрямую из публичного
  API Bybit (бессрочные USDT-перпетуалы, спот как запасной).
- Watchlist с живыми ценами, неоновая вспышка карточки при новом сигнале.
- Кнопка **🤖 Совет агентов**: стратегия для контекста подбирается
  автоматически под свежий график (быстрый бэктест всех стратегий),
  агенты опираются на собственный анализ и стримят вердикты в модалке.

### ⚡ Сигналы
- Live-лента сигналов по watchlist'у: индикаторная математика, **AI-токены
  не тратятся вообще** (AI — только по клику).
- Звук (различающий лонг/шорт) + всплывающие уведомления — выключаются тумблерами.
- Клик по карточке сигнала → мгновенно открывается его график.

### 💼 Мои сделки
- Подтягивает **вашу реальную историю** с Bybit двумя путями:
  1. **Read-only API-ключи** (Bybit → API Management → Create New Key →
     отметить *Read-Only!* — платформа никогда не торгует, только читает);
  2. **CSV-экспорт** (перетащите файл на страницу).
- Статистика: PnL, winrate, profit factor, средний профит/убыток, сделок в день,
  кривая эквити, раскладка по монетам, последние сделки, авто-паттерны.
- **🤖 AI-разбор торговли**: отдельный агент-аналитик холодно разбирает
  историю — сильные стороны, повторяющиеся ошибки, рекомендации, риски депозита,
  оценка дисциплины 1–10.

### ⚙️ Настройки
- Глобальный ключ `justcode.lol` + загрузка **списка доступных моделей**
  (`GET /models` вашего endpoint'а) — любую модель можно назначить любой роли.
- Тумблеры ролей (выключенный агент не вызывается — токены не тратятся).
- Watchlist, интервал сканера, порог уверенности, звук/всплывашки.
- Все настройки сохраняются локально в `portal/.env` (создаётся автоматически;
  в git не попадает — ключи не утекут).

## Экономия токенов (по дизайну)

Портал **никогда не вызывает AI сам по себе**: сканер сигналов — чистая
математика по свечам. Модели вызываются только когда вы нажимаете
«Совет агентов» или «AI-разбор». Выключенные тумблером роли не вызываются
даже по кнопке.

## Прочее

- Порт полностью независим: **3005** (меняется в `portal/.env` → `PORTAL_PORT`).
- Если Bybit недоступен с вашей сети (гео-блок), данные отмечаются бейджем
  «⚠️ Учебные данные», есть авто-перебор хостов `api/api2/bytick/bybit.eu`
  (проверка — кнопка «🔍 Проверить» в Настройках).
